tanzaku プライバシーポリシー

最終更新日: 2026 年 5 月 27 日

本ポリシーは、Android / iOS 向けアプリ「tanzaku」（以下「本アプリ」）におけるユーザーデータの取り扱いについて定めるものです。本アプリを利用することにより、本ポリシーに同意したものとみなします。

1. 本アプリの概要

本アプリは、日本語で書かれた Web コンテンツ（青空文庫・小説家になろう・カクヨム等）を縦書き表示で閲覧するためのブラウザアプリです。

2. 取得・保存するデータ

2.1 端末内にのみ保存されるデータ

以下のデータは端末内（OS が提供するローカルストレージ）にのみ保存され、外部のサーバーには送信されません。

  • 直前に開いていた Web ページの URL（再起動時にセッションを復元するため）
  • 文字サイズ設定
  • リワード動画視聴による広告非表示の解除時刻
  • サブスク加入状態のキャッシュ

2.2 第三者サービスを通じて送信されるデータ

本アプリは以下の第三者サービスを利用しており、これらのサービスを通じて一部のデータが送信されます。

Google AdMob（広告配信）

  • 広告 ID（Advertising ID / AAID・IDFA）
  • IP アドレス、デバイス情報（OS バージョン、機種等）
  • 概略位置情報

詳細は Google 広告ポリシー および Google プライバシーポリシー を参照してください。

RevenueCat（サブスク管理）

  • 匿名のユーザー ID（RevenueCat が自動生成）
  • 購入レシート（Apple / Google が発行した検証用情報）
  • デバイス情報、アプリバージョン

詳細は RevenueCat プライバシーポリシー を参照してください。

Apple App Store / Google Play

  • サブスク購入時、各ストアが定めるレシート・購読状態情報がストアと本アプリの間でやり取りされます

3. 利用目的

  • セッションの復元（前回開いていたページに戻る）
  • ユーザー設定（文字サイズ等）の保存
  • 広告の配信および表示頻度の最適化（AdMob）
  • サブスクリプションの購入処理および購入状態の管理（RevenueCat、Apple、Google Play）
  • 不正利用の防止、品質改善

4. 保存期間

  • 端末内のデータ: 本アプリをアンインストールした時点で削除されます
  • 第三者サービスのデータ: 各サービスの定めるポリシーに従います

5. ユーザーの選択肢

  • 広告 ID のリセット・無効化: Android は「設定」→「Google」→「広告」、iOS は「設定」→「プライバシーとセキュリティ」→「Apple 広告」から操作できます
  • サブスクの解約: 本アプリ内の「設定 / サブスク」→「サブスクを管理・解約」から、または各ストアの定期購読管理画面から行えます
  • 端末内データの削除: 本アプリをアンインストールすることで削除されます
  • データに関するお問い合わせ: 下記連絡先までご連絡ください

6. 子どもの利用について

本アプリは 13 歳未満（米国では COPPA、EU では GDPR が定める年齢）の子どもを対象としていません。13 歳未満のお子様による利用が判明した場合は、関連データを速やかに削除いたします。

7. 第三者サイトへのリンク

本アプリは WebView を通じて第三者の Web サイトを表示します。これらのサイトのコンテンツおよびプライバシー慣行については、各サイトのポリシーを参照してください。本アプリは第三者サイトのコンテンツについて責任を負いません。

8. 本ポリシーの変更

本ポリシーは予告なく改定されることがあります。重要な変更がある場合は、本ページ上で告知します。
