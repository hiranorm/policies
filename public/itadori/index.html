itadori プライバシーポリシー

最終更新日: 2026 年 6 月 19 日

本ポリシーは、Android / iOS 向けアプリ「itadori(板取/いたどり)」(以下「本アプリ」)におけるユーザーデータの取り扱いについて定めます。本アプリを利用することにより、本ポリシーに同意したものとみなします。

1. 本アプリの概要

本アプリは、板書(黒板・ホワイトボード・手書きメモ)を撮影し、AI による文字認識(OCR)を通じて Markdown 形式のノートへ変換し、ユーザー自身の Google Drive に保存するアプリです。本アプリの運営者(開発者)は独自のバックエンドサーバーを持たず、データの送信はすべて端末から各 Google サービスへ直接行われます。

2. 端末内にのみ保存されるデータ

以下のデータは端末内のローカルストレージにのみ保存され、開発者のサーバーには送信されません。

OS の暗号化ストレージ(iOS Keychain / Android Keystore、expo-secure-store 経由)

  • Google OAuth アクセストークン / ID トークン / 付与されたスコープ
  • 変換クレジットの残数、リワード広告の初回視聴状態
  • 「学習データの送信」設定値(現在は送信機構が無く、値を保持するのみ)

本アプリは、撮影画像や生成した Markdown の本文を端末に永続化しません。

3. Google アカウント / Google Drive を通じて扱うデータ

本アプリはユーザーの操作に応じて Google の API を直接呼び出します。以下はすべて端末と Google の間で完結し、開発者のサーバーには送信されません。

  • OAuth ログインで Google から受け取るメールアドレス(ログイン中アカウントの表示・認証に使用)
  • 撮影した原画像(JPEG): ユーザーの Drive 内 itadori/originals/ フォルダに保存
  • 生成した Markdown ノート: ユーザーの Drive 内 itadori/ フォルダに保存

本アプリは drive.file スコープのみを要求します。これは「本アプリが作成したファイル」および「ユーザーが明示的に選択したファイル」に限ってアクセスできる権限であり、ユーザーの Drive 全体を読み取ることはできません。詳細は Google プライバシーポリシー を参照してください。

4. AI(Google Gemini)への画像送信

本アプリは板書を文字へ変換するため、撮影画像を Firebase AI Logic 経由で Google の Vertex AI(Gemini 3.1 Flash-Lite モデル)に送信します。

  • 送信される画像は OCR(文字認識)処理のためにのみ使用されます。
  • 送信された画像は Google の生成 AI モデルの学習には使用されません(Vertex AI / Google Cloud の規約)。
  • 開発者のサーバーには画像を保持しません。

5. 不正利用防止(Firebase App Check)

改変版アプリや不正アクセスを防ぐため、Firebase App Check により端末・アプリの正当性を示すトークン(Android: Play Integrity / iOS: App Attest)を Firebase に送信します。これは個人を識別する情報ではありません。

6. 広告(Google AdMob)

本アプリは API コストを賄うため、ユーザーが自発的に視聴するリワード(報酬型)動画広告を表示します。広告は本人が視聴ボタンを押したときのみ表示され、強制表示は行いません。広告配信のため AdMob(Google LLC)へ以下が送信されます。

  • 広告 ID(AAID / IDFA)
  • IP アドレス由来の概略位置情報、デバイス情報(OS バージョン・機種等)

EEA / 英国 / スイスのユーザーには、初回起動時に同意管理プラットフォーム(UMP)を通じて同意を取得します。同意しない場合でも、個人化されない広告または制限付き広告で本アプリを利用できます。詳細は Google 広告ポリシー を参照してください。

7. 学習データについて

本アプリには「学習データの送信」設定がありますが、現在のバージョンでは送信機構を実装しておらず、同意しても何も送信されません。将来、修正済みノートと原画像を読み取り精度の改善に使う機能を追加する場合は、送信前のプレビューと個別の取り消しを提供する予定です。

8. 第三者サービス

本アプリは、上記の Google サービス(Google アカウント / Google Drive / Vertex AI[Gemini] / Firebase App Check / AdMob)以外の第三者サービスを利用していません。

9. 利用目的

  • 撮影画像の OCR と Markdown 化
  • 生成したノート・原画像のユーザー Drive への保存
  • ログイン中の Google アカウント(メール)の画面表示
  • 広告の配信および表示頻度の最適化(AdMob)
  • 本アプリの不正利用の防止(Firebase App Check)

10. 保存期間

  • 端末内の OAuth トークン: ログアウトまたはアンインストールで削除されます
  • Google Drive 上の画像・ノート: ユーザー自身の Drive 内に存在し続けます。開発者側に複製を保持しません
  • Google が保持するデータ: Google のプライバシーポリシーに従います

11. ユーザーの選択肢

  • Drive アクセス権の取り消し: Google アカウントの 「サードパーティ アプリとサービス」 から「itadori」を選んでアクセス権を削除してください
  • データの削除: Google Drive 上の itadori/ フォルダを削除してください。開発者側に複製はありません
  • 端末内トークンの削除: 本アプリをアンインストールしてください
  • 広告 ID のリセット: Android は「設定 → Google → 広告」、iOS は「設定 → プライバシーとセキュリティ → トラッキング / Apple 広告」から操作できます
  • 広告の同意設定の変更(EEA/UK/スイス): 本アプリ内「設定 → 広告のプライバシー設定」から変更できます
  • お問い合わせ: 下記連絡先までご連絡ください

12. 子どもの利用について

本アプリは 13 歳未満(米国では COPPA、EU では GDPR が定める年齢)の子どもを対象としていません。13 歳未満のお子様による利用が判明した場合は、関連データを速やかに削除いたします。
