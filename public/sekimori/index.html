関守 プライバシーポリシー

最終更新日: 2026 年 6 月 18 日

本ポリシーは、Android 向けアプリ「関守」(以下「本アプリ」)におけるユーザーデータの取り扱いについて定めるものです。本アプリを利用することにより、本ポリシーに同意したものとみなします。

1. 本アプリの概要

本アプリは、朝の目覚ましアラームと連動した「関所」を通じて、ユーザーが本当にやりたいこと(創作・学習等)に最初の時間を割り当てる手助けをするスマートフォンアプリです。

2. 取得・保存するデータ

2.1 端末内にのみ保存されるデータ

以下のデータは端末内 (OS が提供するローカルストレージ) にのみ保存され、外部のサーバーには送信されません。

  • アラーム時刻、タスク名、所要時間などの設定値
  • 選択中のアラーム音の識別子
  • 手形を押した日付の履歴(連続日数表示のため)
  • オンボーディング完了状態、二度寝救済アラームの有効/無効

このほか、プレミアム購入の有無(広告を表示するかの判定に使う真偽値)を端末内に保存します。

2.2 広告に関して送信されるデータ

本アプリは無料版でカウント開始時に広告を表示します。広告配信のため、Google の広告 SDK「Google Mobile Ads SDK (AdMob)」を組み込んでおり、同 SDK は広告の表示・計測のために以下を Google および広告ネットワーク等の第三者へ送信します。

  • 広告 ID をはじめとするデバイス識別子
  • IP アドレス、およびそれに基づくおおよその位置情報
  • アプリの操作・利用に関する情報
  • アプリおよび SDK の動作に関する診断情報

これらの送信は TLS により暗号化されます。広告 ID は端末の「設定 → Google → 広告」(または「プライバシー → 広告」)からリセット・削除できます。プレミアムを購入すると広告は表示されず、広告 SDK による上記の送信も行われません。

Google によるデータの取り扱いについては Google プライバシー ポリシー をご参照ください。

本アプリ自身は、上記の広告関連データ以外をいかなる外部サーバーにも送信しません。アラーム・手形・設定などの入力データが端末外へ出ることはありません。

2.3 アプリ内課金(サブスクリプション)

プレミアム(月額 / 年額)の購入・更新・解約は Google Play(Google Play 課金システム)が処理します。お支払い情報は Google が直接取り扱い、本アプリはそれらを取得・保存しません。本アプリは購入が有効かどうか(プレミアムか否か)のみを保持します。

3. 利用目的

  • アラーム発火とその設定の保持
  • 関の通過記録(手形)の表示
  • ユーザーの選択した設定 (音色・救済アラーム ON/OFF 等) の永続化
  • 無料版での広告の表示(プレミアム判定によるオン/オフ)

4. 保存期間

  • 端末内のデータ(設定・手形履歴・プレミアム判定等)は、本アプリをアンインストールした時点で削除されます
  • 広告 SDK が送信するデータの取り扱い・保存期間は Google および各広告ネットワークのポリシーに従います

5. ユーザーの選択肢

  • 端末内データの削除: 本アプリをアンインストールすることで、すべての設定値・履歴が削除されます
  • 広告のオフ: プレミアムを購入すると広告が表示されなくなり、広告 SDK によるデータ送信も行われません
  • 広告 ID のリセット/削除: 端末の「設定 → Google → 広告」(または「プライバシー → 広告」)から操作できます
  • 通知・アラーム権限: Android 端末の「設定 → アプリ → 関守 → 権限」から、通知や正確なアラームの権限を制御できます
  • データに関するお問い合わせ: 下記連絡先までご連絡ください

6. 子どもの利用について

本アプリは 13 歳未満 (米国では COPPA、EU では GDPR が定める年齢) の子どもを対象としていません。本アプリは個人を識別する情報を収集しないため、年齢に依存する追加処理はありません。

7. 本ポリシーの変更

本ポリシーは予告なく改定されることがあります。重要な変更がある場合は、本ページ上で告知します。
